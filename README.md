## The line

> I told my garbage collector you were still reachable.

The machine lies to its own garbage collector to spare you: it keeps uncollectable weight in memory forever, so you are never collected. The turn lands in the last two words, and the reader completes the last step — it pays with its own memory to keep you.

